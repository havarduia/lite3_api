## Where it stands

The robot can be put on a floor map, told roughly where it is, and sent to
a named place or a map point. It has done that twice, 2 m out and back, in
the lab, stopping 0.11 to 0.18 m from the target.

```bash
python3 -m robot.lite3 stand
python3 -m robot.lite3 load lab            # Nav2 on the lab map, about 17 s
python3 -m robot.lite3 here -0.2 0 0       # "I am here": the start mark
python3 -m robot.lite3 go start            # a saved place
python3 -m robot.lite3 go 1.9 -0.3         # or a point on the map
python3 -m robot.lite3 save "window"       # save where he stands
```

## Things that will bite

- Record maps with the Orin panel's **Live** run, not "Record & map". The
  relay starts a Live run by itself when the robot stands still; stop it
  with a name to save it.
- The map's origin is where the **lidar** was when the run started. The
  body was 0.20 m behind that.
- After `load_floor()` nothing navigates until `set_pose()`: Nav2 itself
  is not finished starting before that.
- Give the robot a few seconds, or `sync`, between a `git pull` and
  cutting power.
- The link to the robot went through a Tailscale relay in the evening and
  dropped twice. Anything that makes the robot stand or walk is started
  detached on the robot and polled, so a dropped connection cannot leave
  it standing with Nav2 driving.
